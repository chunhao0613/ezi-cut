# EziCut — 瀏覽器影片剪輯器

完全在瀏覽器本機運作的免費影片剪輯網站，不上傳任何檔案、不需要安裝。

## 啟動

```bash
npm install
npm run dev
```

打開 http://localhost:5173 。

## 免費架設到 GitHub Pages

1. 在 GitHub 建立一個新的 repository，把這個專案推上去（本機已是 git 專案，分支為 `main`）：`git remote add origin <repository 網址>`，再 `git push -u origin main`
2. 到 repository 的 **Settings → Pages**，把 **Source** 改成 **GitHub Actions**
3. 之後每次推送到 `main`，[.github/workflows/deploy.yml](.github/workflows/deploy.yml) 會自動編譯並發佈到 `https://你的帳號.github.io/專案名稱/`

網站主程式約 170 KB（壓縮後約 70 KB）；匯出、AI 去背、字幕、翻譯、語音等程式只在使用時才下載；AI 模型從 Hugging Face 等處下載並快取在使用者瀏覽器，不佔 GitHub 空間。

## 目前功能（v0.3）

所有處理（剪輯、特效、匯出、AI 辨識）都在使用者自己的電腦上進行，檔案與聲音不會上傳，網站方也沒有伺服器成本。

### 媒體與專案
- 匯入影片、音樂、圖片：按鈕選檔，或直接把檔案拖進視窗 / 拖到時間軸指定位置
- 自動產生影片縮圖條與音訊波形
- 媒體檔存在瀏覽器（IndexedDB），專案自動儲存，重新整理或關掉再開都還在
- 第一個加入的影片會自動把畫布設成相同比例
- 畫面比例：16:9、9:16、1:1、4:5、4:3、21:9、4K；影格率 24 / 25 / 30 / 60 fps；可改背景色
- 復原 / 重做最多 200 步
- **專案檔**：把專案連同用到的素材、LUT 匯出成一個 .ezicut 檔，可備份或換電腦繼續剪

### 多軌時間軸
- 軌道數量不限，可新增、刪除、改名、隱藏畫面、靜音
- 拖曳移動片段（可跨軌）、拖左右邊緣修剪，修剪不會超出素材長度或撞到相鄰片段
- 磁吸對齊片段邊緣與播放頭，顯示對齊線
- 放到已被佔用的位置時，自動找最近的空軌道（必要時新增軌道）
- 分割（單一片段或播放頭下全部片段）、複製、複製貼上、刪除
- 時間軸縮放（滑桿、按鈕、Ctrl+滾輪、一鍵適合畫面）、可拖曳調整時間軸高度
- **倒放**：在本機把片段倒過來重新編碼，預覽與匯出都流暢，可隨時取消
- **定格**：在播放頭插入 1–5 秒定格畫面，後面的片段自動往後推
- **裁切**：上下左右各自裁切
- 片段上會標示入場 / 出場動畫範圍與關鍵影格位置
- **片段之間的轉場**：同一軌相鄰兩段的接縫處有轉場按鈕，可選 18 種轉場與長度，後一段會往前疊上並交叉淡化聲音，可隨時移除

### 畫面編輯
- 位置、縮放、旋轉、不透明度，全部可設**關鍵影格**（平滑緩動）
- 一鍵 Ken Burns 推近 / 拉遠
- 直接在預覽畫面點選、拖曳移動、拉四角縮放、旋轉把手（Shift 每 15° 對齊）、滾輪縮放，有置中參考線
- 完整顯示 / 填滿裁切 / 拉伸；**模糊背景**（橫式影片轉直式必備）
- 17 種混合模式；水平鏡像、垂直翻轉

### 調色與特效
- **專業調色（WebGL GPU）**：白平衡（色溫、色調）、三個色輪（暗部 / 中間調 / 亮部，含亮度）、曲線（主曲線與紅綠藍各自調整、一鍵 S 曲線）、3D LUT（6 款內建風格，可匯入 .cube 並調整強度）
- 調整：亮度、對比、飽和度、色相、模糊、黑白、懷舊、反相（改由 GPU 處理，iPhone / Safari 也有效果）
- 14 種一鍵濾鏡：電影感、復古底片、黑白、鮮豔、暖陽、冷調、夢幻、賽博龐克、褪色、夜視、負片、日系清新、港風等
- 風格特效：暗角、底片顆粒、馬賽克、故障、RGB 分離
- **綠幕 / 藍幕去背**：可調相似度、邊緣柔化，並自動去除綠邊
- **AI 人像去背（不需綠幕）**：MediaPipe 人像分割在本機以 GPU 執行，每格約 8 ms，可調主體範圍與邊緣柔化，預覽與匯出都有效
- **遮罩**：矩形（可圓角）、圓形、線性、鏡面、愛心、星形；可調位置、大小、旋轉、羽化，可反轉，遮罩跟著片段移動
- **運動追蹤**：把文字、貼圖或圖片放在影片中的物體上，一鍵追蹤，位置自動寫成關鍵影格（跟丟一秒會自動停止）

### 動畫
- 18 種入場 / 出場動畫：淡入淡出、四方向滑入、放大 / 縮小進場、旋轉、彈跳、模糊、四方向擦除、圓形展開、閃白、震動、故障風；時長可調

### 文字轉語音
- 在本機合成語音：中文用 Piper（華研女聲），英文用 Kokoro（5 種美式 / 英式男女聲），另有西、法、德、越文聲音
- 文字片段可一鍵「念出這段文字」，語速 0.6–1.6 倍

### 範本（剪同款）
- 7 款內建範本：旅行 Vlog 開場、六連拍卡點、產品介紹、生日祝福、Before / After 對比、倒數開場、限時動態
- 套用時依序選擇自己的照片 / 影片填入每個素材位置，並修改範本文字；空著的位置在預覽中顯示「＋ 素材 N」
- 可把目前專案存成自己的範本（勾選哪些素材可替換，其餘素材與音樂跟著保存），並匯出成檔案分享給別人、匯入別人的範本

### 文字、貼圖、素材
- 12 種文字樣式：大標題、字幕、霓虹、漸層、打字機、彩虹波浪、綜藝字、電影片名、手寫、像素遊戲、書法、標籤
- 12 款字體（含思源黑體、思源宋體、霞鶩文楷等中文字型）
- 文字顏色 / 漸層、描邊、陰影與發光、底框、粗細、斜體、對齊、字距、行高、多行
- 5 種文字持續動畫：打字機、波浪、彩虹、霓虹閃爍、心跳
- 66 個表情貼圖
- 11 種素材：矩形、圓角矩形、圓形、字幕條、黑幕、白幕、4 種漸層背景、電影黑邊

### 音訊
- 音量 0–300%、淡入淡出、單一片段靜音
- **人聲增強**：RNNoise AI 降噪（可調強度）、人聲 EQ 與壓縮、音量標準化，在本機處理後產生新音訊，可隨時還原
- 從影片分離音訊成獨立片段
- 變速 0.1×–16×，**預覽與匯出都能保持音高**（自製 WSOLA 演算法，也可關閉以做變調效果）
- **曲線變速**：8 種預設（蒙太奇、英雄時刻、子彈時間、跳接、閃進、閃出、漸快、漸慢），可拖曳控制點自訂曲線；分割時曲線自動接續
- **節拍偵測**：自動找出音樂的 BPM、每一拍與每小節第一拍，時間軸上以黃色刻度標示，拖曳片段會吸附到節拍
- **一鍵卡點**：把畫面軌道上的影片 / 圖片依序對齊到每拍、每 2 拍、每 4 拍或只用重拍
- **自動剪掉靜音**：可調音量門檻與最短靜音長度，剪掉後後面的片段自動往前補，拆出的音訊與字幕一起對齊

### AI 自動字幕
- 使用 Whisper 語音辨識（[transformers.js](https://github.com/huggingface/transformers.js)），在背景執行緒中於本機執行，聲音不上傳
- 支援 8 種語言與自動偵測：中文、英文、日文、韓文、粵語、西班牙文、法文、德文
- **依裝置自動推薦模型**：偵測顯示卡、記憶體、CPU 與是否為手機，把 4 種模型（Tiny / Base / Small / Large v3 Turbo）依推薦程度排序；每個模型標示下載大小、是否已下載、在這台裝置上的速度與準確度；不建議的模型仍可選
- 有 WebGPU 時用顯示卡加速，失敗時自動改用 CPU 重試
- 自動轉成繁體中文（台灣用語，[opencc-js](https://github.com/nk2028/opencc-js)）
- 長句自動切成適合螢幕閱讀的短句
- 字幕放在獨立字幕軌；字幕列表可直接改字、點時間跳到該句、一鍵把樣式套用到全部、全部刪除
- SRT 匯入 / 匯出（原文、譯文或雙語）
- **字幕翻譯 / 雙語字幕**：Chrome 使用瀏覽器內建的裝置端翻譯，其他瀏覽器改用 Opus-MT 在本機翻譯（沒有直接語言組合時自動經英文轉譯）；譯文可放在原文下方成為雙語字幕，或直接取代原文；支援繁中、簡中、英、日、韓、西、法、德、越、印尼、泰
- **字幕配音**：一鍵把所有字幕念出來放到「配音」軌，念不完的句子自動加快（最多 1.6 倍），後一句自動往後排不重疊

### 輸出
- **快速匯出**（[Mediabunny](https://github.com/Vanilagy/mediabunny) + WebCodecs）：逐格解碼、合成、編碼，不必等影片播完，切到其他分頁也會繼續，可中途取消
- **影片**：MP4、MOV、WebM、MKV、MPEG-TS；影片編碼 H.264 / H.265 / AV1 / VP9 / VP8，音訊 AAC / Opus / MP3 / FLAC / PCM（只顯示這台電腦能編碼的組合）
- 解析度（原始、4K、2K、1080p、720p、480p、360p 或自訂寬度）、影格率（23.976–60 fps）、畫質（低到極致或自訂位元率）、匯出範圍（整段、選取片段、從播放頭起、自訂起訖）、可不含聲音，並顯示預估檔案大小
- **只要聲音**：MP3、M4A、WAV 16 / 24-bit、FLAC、OGG（Opus）、AAC
- **GIF 動圖**、**圖片序列**（PNG / JPG / WebP 打包成 ZIP）、**單張畫面**（PNG / JPG / WebP，可放大到 4K）
- 10 種平台預設：YouTube 1080p / 4K、TikTok / Reels / Shorts、Instagram、LINE / Discord 小檔、剪輯交換 MOV、網頁 WebM、Podcast MP3、無損 WAV、貼圖 GIF
- 不支援 WebCodecs 的瀏覽器自動改用即時錄製
- 單張畫面截圖存成 PNG

### 快捷鍵
空白鍵播放 / 暫停、S 分割、Delete 刪除、Ctrl+Z / Ctrl+Shift+Z 復原 / 重做、Ctrl+D 複製片段、Ctrl+C / Ctrl+V 複製貼上、← → 前後一格（Shift = 1 秒）、Home / End、+ / - 縮放、Esc 取消選取

### 手機與平板
- 不用安裝 App，手機瀏覽器打開就能剪
- 手機版介面：上方預覽，下方以「素材 / 編輯 / 時間軸」分頁切換，按鈕與修剪把手加大
- 觸控操作：直接拖曳片段、空白處滑動捲動時間軸、輕點移動播放頭、兩指縮放時間軸；預覽畫面上兩指縮放與旋轉選取的片段

## 瀏覽器支援與已知限制

- **建議使用電腦版 Chrome 或 Edge**，所有功能都可用
- **手機**：已有手機版介面；但素材庫拖曳到時間軸的功能在觸控裝置上不支援（請用「＋」加入）
- **iPhone / iPad**（所有 iOS 瀏覽器都使用 Safari 核心）：調色與濾鏡已改由 WebGL 處理而能生效，但模糊、遮罩羽化、AI 去背邊緣柔化仍沒有效果；快速匯出與顯示卡加速 AI 需要 iOS 26 以上，較舊版本會改用即時錄製與 CPU
- 匯出速度取決於使用者裝置的編碼器，舊電腦可能比即時播放還慢
- Large v3 Turbo 在顯示卡模式下使用 4-bit 版本以減少下載量，準確度尚未完整測試
- 在 GitHub Pages 上，AI 字幕用 CPU 執行時只能單執行緒，速度較慢（顯示卡模式不受影響）

## 架構

| 檔案 | 用途 |
| --- | --- |
| `src/state.js` | 專案資料模型、事件、復原 / 重做、分割 / 擺放 / 關鍵影格 |
| `src/renderer.js` | Canvas 合成器：每幀把所有片段、特效、轉場畫出來，並同步影音元素 |
| `src/timeline.js` | 多軌時間軸的繪製與拖曳互動 |
| `src/inspector.js` | 右側屬性面板 |
| `src/library.js` | 左側素材庫 |
| `src/effects.js` | 轉場、濾鏡、文字預設等定義 |
| `src/media.js` / `src/db.js` | 媒體匯入、縮圖、波形、IndexedDB 保存 |
| `src/exporter.js` | WebCodecs 離線快速匯出（解碼 → 合成 → 編碼 → 封裝） |
| `src/captions.js` / `src/asr.worker.js` | AI 字幕：音訊擷取、模型排序與精度選擇、Whisper（Web Worker）、斷句、SRT |
| `src/device.js` | 偵測裝置強度（顯示卡、記憶體、CPU、手機），用來推薦模型 |
| `src/timestretch.js` | WSOLA 變速不變調 |
| `src/timemap.js` | 片段時間與素材時間的換算（固定速度與曲線變速） |
| `src/tools.js` / `src/reverse.js` / `src/beats.js` | 定格、倒放、節拍偵測與卡點、自動剪靜音、人聲增強套用 |
| `src/grade.js` | WebGL2 調色（濾鏡、白平衡、色輪、曲線、3D LUT） |
| `src/matte.js` / `src/track.js` / `src/voice.js` | AI 人像去背、運動追蹤、人聲增強 |
| `src/translate.js` / `src/translate.worker.js` | 字幕翻譯（Chrome 內建翻譯，或 Opus-MT） |
| `src/tts.js` | 文字轉語音（Piper、Kokoro） |
| `src/templates.js` | 內建範本、存成範本、套用、匯出匯入 |
